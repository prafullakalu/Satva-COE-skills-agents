# Brand voice and style guide

Voice is who you sound like all the time; tone is how it adapts to the moment. A guide is useful only if a new writer (or an AI) can apply it without asking.

## Workflow

### 1. Gather samples (minimum 10)
Best pieces from the site, sales emails, proposals, support replies, social posts, founder writing, and customer-facing docs. Add 3-5 samples that feel off-brand and 3 competitor samples. Collect customer-feedback phrases about how you communicate. No samples? Interview 3 leaders and 3 customers and label the result `[Aspirational]`.

### 2. Analyse patterns
Note: sentence length, formality, person (we/you/I), humour, jargon level, use of numbers, directness, openers and closers, characteristic words and words that never appear. Compare against competitors to find distinct ground.

### 3. Choose 3-4 voice attributes
Each as "X, not Y" so the boundary is clear: e.g. **Plain, not simplistic**; **Direct, not blunt**; **Expert, not academic**; **Warm, not casual**. For each attribute write:
- What it means in practice (2 sentences).
- Do: two real example sentences.
- Don't: two sentences that overshoot or undershoot.
- A rewrite showing the difference.
Four attributes maximum; more cannot be remembered.

### 4. Define tone by context
| Context | Tone shift | Example constraint |
|---|---|---|
| Website / sales | Confident, outcome-focused | Lead with the reader's result |
| Support / incident | Calm, accountable | Own the issue, state next step and time |
| Social | Conversational, opinionated | First-person, short, no corporate we |
| Technical docs | Precise, neutral | No metaphor, steps in order |
| Proposals / legal-adjacent | Formal, exact | Every commitment dated and measurable |
| Bad news | Direct first, empathy second | No spin |

### 5. Vocabulary and terminology
- **Preferred terms** table (use / avoid / why): customer vs client, integration vs connector, "AI agent" vs "bot".
- **Banned filler:** "leverage", "synergy", "world-class", "robust", "cutting-edge", "seamless", "unlock" (list yours).
- **Product and platform names:** exact spelling and capitalisation (QuickBooks, Xero, Shopify, Linnworks).
- **Jargon policy:** which technical words are fine for which audience; expand acronyms on first use.

### 6. Mechanics
Spelling variant (US or UK), Oxford comma, headline case (sentence case recommended), numbers and dates, currency format, contractions, bullet and heading rules, emoji policy, link text, alt text, inclusive language, accessibility (reading level target, e.g. grade 8-10 for web).

### 7. The on-brand test (include in the guide)
A draft passes if: (1) it matches at least 3 attributes in the examples; (2) a reader could not swap in a competitor's name and keep it true; (3) it has no banned terms; (4) the first sentence earns the second; (5) read aloud, it sounds like a person at the firm. Provide 3 before/after rewrites.

### 8. Make it usable
Deliver as a one-page summary plus detailed sections. Include a prompt block that can be pasted into AI tools:
```
Write in [brand]'s voice: [attributes with one-line meaning]. Use plain words, short sentences, active verbs.
Avoid: [banned list]. Terminology: [list]. Spelling: [variant]. Never invent facts or statistics.
```
Name an owner and a review cadence (twice a year); log changes.

## Audit mode
When auditing, score each sample 1-5 on each attribute and on consistency, list the top 10 deviations with fixes, and recommend whether to update the content or the guide.

## Output
Guide document: summary page, attributes with examples, tone matrix, vocabulary table, mechanics, on-brand test, AI prompt block, change log.

## Failure modes
- Adjective soup ("friendly, innovative, professional") that distinguishes nothing.
- A guide with no examples.
- Describing the voice you want while samples show another and not saying which wins.
- Locking style rules that fight accessibility or plain language.
