What this is

The Satva Shopify MCP connects your Shopify store to the AI tools you already use — Cursor, Claude, or VS Code — so you can ask them about products, orders, customers, and inventory in plain language.

It is for Satva staff and the merchants they support. There is nothing to install and no software to run on your machine: you sign in to a web page, connect your store, and paste two lines of configuration into your AI tool.

Setup takes about five minutes and is done once per store.

Before you start

  • A Satva Google account (@satvasolutions.com) to sign in with.
  • Permission to install apps on the Shopify store you want to connect — Shopify will ask you to approve access.
  • Your store's myshopify.com address. A custom domain such as shop.example.com will not work.
  • An AI tool that supports MCP: Cursor, Claude Desktop / Claude Code, or VS Code.

Not sure of your myshopify.com address? In Shopify admin go to Settings → Domains. The address ending in .myshopify.com is the one this guide needs.

You never paste a Shopify client ID or secret anywhere. Satva runs one shared Shopify Partner app for everyone, so there is no bring-your-own-app step in this guide.

1. Sign in

Open https://mcp.example.com in your browser. You will land on the sign-in page.

After signing in you land on the control panel. It has exactly three steps and you work through them in order.

2. Connect your store

Step 1 is headed Connect store, with the hint "Type your store address. You will be sent to Shopify to approve access — nothing to copy or paste."

  1. Type your store address. Both your-store.myshopify.com and just your-store are accepted.
  2. Click Connect Shopify. Your browser is sent to Shopify.
  3. On Shopify's own screen, review the permissions and approve the install. This happens in Shopify, not in the Satva panel.
  4. You are returned to the panel. A green banner confirms "Store connected — Pick the active store in step 2 if you connected more than one."

Start the connection yourself, from step 1 in your own browser. Never finish a Shopify connect link that someone else sent you — the panel deliberately rejects an install that began in a different browser.

3. Choose the active store

Step 2 is headed Choose store, with the hint "If you connected more than one store, choose which one the tools should use." You can connect as many stores as you like to one account, but exactly one is Active at a time, and the tools only reach the active one.

  • With one store connected, there is nothing to do here — it is active automatically.
  • With more than one, the top banner reads "Pick your active store — More than one store is connected. Choose which one the tools should use in step 2."
  • Before you connect anything, this step shows "No stores yet — finish step 1 first."

4. Copy your key and configuration

Step 3 is headed Use in your AI tools, with the hint "Copy the config below into your MCP client." It gives you three things: the MCP server URL, your personal key, and a ready-made configuration block for each supported tool.

The panel says it plainly: "Your personal key — treat it like a password. Anyone holding it reaches your Shopify store." Do not email it, paste it into a chat, or commit it to a repository.

If your key is ever exposed, click Regenerate key. The panel asks you to confirm, because — in its own words — "The old one stops working immediately and every client using it must be updated." After regenerating, copy the new configuration into every AI tool you had set up.

The Cursor block looks like this, with svk_your-personal-key replaced by your own key:

{
  "mcpServers": {
    "Satva Shopify": {
      "url": "https://mcp.example.com/mcp",
      "headers": {
        "Authorization": "Bearer svk_your-personal-key"
      }
    }
  }
}

The Claude block is the same shape. The VS Code block uses servers instead of mcpServers and adds "type": "http".

Obot users: where the deployment is set up with an Obot connect URL, step 3 shows that URL instead and no API key is needed — you stay signed in through Obot. The key and Regenerate key button are not shown at all.

5. Add it to your AI tool

Copy the block from the tab that matches your tool, then paste it where that tool keeps its MCP settings.

ToolTab to useWhere to paste

If the file already has other MCP servers in it, add the "Satva Shopify" entry alongside them rather than replacing the whole file.

Save the file and restart your AI tool. Then check it works by asking:

list my 10 most recent orders

If the tool answers with orders from your store, setup is complete. If it says it has no Shopify tools available, the configuration was not picked up — check the file, save it, and restart the tool again.

Permissions explained

Satva's Shopify app asks for a fixed set of Admin API scopes, and you approve them once, in Shopify, during step 1. They cover:

  • Products, inventory, and locations
  • Orders, draft orders, fulfillments, and returns
  • Customers, companies, and checkouts
  • Discounts and gift cards
  • Markets, shipping, and analytics
  • Content, themes, files, and metaobjects

Each is requested as read or write as configured for the app. The exact list is always visible in the panel under What access is requested? in step 1 — that expanded list, not this guide, is the authority.

If something goes wrong

The panel shows a banner at the top when a connection attempt fails. Find the banner title below.

Banner titleWhat to do
That does not look like a Shopify store address Enter the store as your-store.myshopify.com (or just your-store). Custom domains such as shop.example.com do not work — take the myshopify.com address from Shopify admin → Settings → Domains.
Install cancelled You declined the permission request in Shopify. Click Connect again when you are ready.
Shopify callback failed verification The install response could not be verified. Start the connection again from step 1.
Redirect URI mismatch A server-side configuration problem. The banner shows the exact redirect URL that must be registered on the Shopify Partner app — send that line to your Satva admin.
Connection link expired The install took too long to complete. Start again from step 1.
That install link was not started in this browser A store can only be connected by the same browser that began the install. Never finish a Shopify connect link someone else sent you — start it yourself from step 1.
Could not start the Shopify install Something went wrong talking to Shopify. Check the store address and try again.
Shopify app is not configured on this server / Shopify app not configured Nothing you can fix from your side. Ask your Satva admin to set the deployment's Shopify credentials, then reload the page.

Other things worth checking:

  • The AI tool shows no Shopify tools. The configuration file was not saved, or the tool was not restarted.
  • The tool reports an authorisation failure. The key in your configuration no longer matches the panel — most often because Regenerate key was used. Copy the current configuration again.
  • Answers come from the wrong store. The wrong store is active. Fix it in step 2 with Use this store.
