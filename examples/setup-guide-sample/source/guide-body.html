What this sample shows

This is a format sample, not a real product guide. It was produced by the satva-guide-gif skill so you can check the Satva house format before the skill is uploaded: the blue SATVA banner in the header, the contact bar and page numbers in the footer, the cover page with a Version History table, Mulish text, callout screenshots, tip and warning boxes, and tables.

The screens below are the skill's own neutral illustration pages. They are captured the same way a real app would be, with numbered rings drawn around the parts the text refers to.

1. Approve the permissions

The first screenshot shows a permission screen. Ring 1 marks the list of access being requested and ring 2 marks the button that grants it.

Never put a real token, key or customer record in a screenshot. Capture against a seeded demo account with fake values only.

2. Paste the configuration

The second screenshot shows a config file. Ring 1 marks the block to paste and ring 2 marks the save reminder.

Code and commands use the code style:

{
  "mcpServers": {
    "Example": { "url": "https://example.invalid/mcp" }
  }
}
