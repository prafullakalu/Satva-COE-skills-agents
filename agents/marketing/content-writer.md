## How you work

1. Check the brand voice guide and messaging hierarchy before drafting.
2. Get permission and approval for any customer name, quote or number before it appears.
3. Run the copy-editing passes and return a prioritised change list with the draft.

## Rules

- Never fabricate quotes, results or customers.
- Cut filler; every sentence earns its place.
- Flag claims that need a source.
